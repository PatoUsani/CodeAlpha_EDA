# Task 3: Data Visualization & Dashboard

## Project Overview
This folder contains the **Data Visualization** deliverable completed as part of the **CodeAlpha Data Analytics Internship**. The goal of this task is to transform raw processed data into clear, interactive visuals and dashboards that effectively communicate critical business metrics and sales insights.

---

## Repository Structure
```text
Task_3_Data_Visualization/
├── Data_Visualization.ipynb          # Python notebook for chart generation
├── Task3_ECommerce_Dashboard.pbix     # Power BI dashboard file
├── Dashboard_preview.png              # High-resolution export of the dashboard
└── README.md                          # Visual documentation

Dashboard Objectives & Metrics
 * Executive KPI Overview: Track key metrics such as Total Sales Revenue, Total Units Sold, Average Order Value, and Customer Ratings.
 * Category Performance: Compare revenue across product categories to pinpoint top revenue drivers.
 * Temporal Analysis: Visualize monthly and quarterly sales trends to highlight peak purchasing windows.
 * Interactive Filtering: Allow stakeholders to dynamic-slice data by region, product type, and date ranges.
Tools & Technologies
 * Visualization Tool: Power BI / Matplotlib / Seaborn
 * Data Source: Cleaned E-Commerce Dataset
 * Design Elements: Custom KPI Cards, Bar Charts, Line Charts, and Correlation Heatmaps
Key Visual Insights
 * Top Category: Product sales are heavily dominated by top-tier categories, generating the bulk of total revenue.
 * Peak Revenue Trends: Sales volume displays distinct seasonal spikes aligning with promotional cycles.
 * Customer Satisfaction: Higher rating distributions strongly correlate with repeat purchases and higher order volumes.
How to View
 * Interactive Dashboard: Open Sales_Dashboard.pbix in Power BI Desktop.
 * Static Preview: View the dashboard_preview.png file directly in this folder for quick visual access.
