# CodeAlpha Data Analytics Internship

## Project Overview
This repository contains the complete deliverables, data analysis workflows, interactive dashboards, and machine learning sentiment models completed for the **CodeAlpha Data Analytics Internship**.

Tasks & Deliverables
​
Task 2: Exploratory Data Analysis (EDA)
​Objective: Perform end-to-end data cleaning, missing value handling, summary statistics, and bivariate feature correlation analysis on the e-commerce sales dataset.
​Key Outputs: Distribution plots, price-quantity correlations, and clean dataset exports.
​Folder: Task_2_EDA/
​
Task 3: Data Visualization & Power BI Dashboard
​Objective: Build an interactive Power BI sales performance dashboard tracking Total Revenue ($1.26M), Total Orders (1K), product performance, payment method breakdowns, and monthly revenue trends.
​Key Outputs: Task3_ECommerce_Dashboard.pbix and high-resolution preview graphics.
​Folder: Task_3_Data_Visualization/
​
Task 4: Sentiment Analysis
​Objective: Clean raw Twitter social media feedback using Regular Expressions, convert text features using TF-IDF Vectorization, and build a Multinomial Naive Bayes classifier for sentiment labeling (Positive, Neutral, Negative).
​
Key Outputs: Sentiment_Analysis.ipynb, Twitter_Data.csv
​Folder: Task_4_Sentiment_Analysis/
​
Technical Stack

​Business Intelligence: Power BI
