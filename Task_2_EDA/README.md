# Task 2: Exploratory Data Analysis (EDA)

## Project Overview
This folder contains the **Exploratory Data Analysis (EDA)** performed on the E-Commerce Sales dataset as part of the **CodeAlpha Data Analytics Internship**. The primary objective of this task is to inspect the data structure, clean raw values, identify underlying trends, and detect key anomalies to drive data-driven decision-making.

---

## Repository Structure
```text
Task_2_EDA/
├── Untitled3.ipynb    # Jupyter Notebook with python code & visual analysis

Key Questions & Analysis Objectives
​Data Integrity: What is the structure of the dataset, and are there missing values or incorrect data types?
​Sales Trends: What are the temporal purchasing patterns across product categories?
​Customer & Regional Insights: How do sales volumes and order distributions vary across regions?
​Anomalies & Outliers: Are there unusual price points or order quantities skewing statistical distributions?
​
Tools & Libraries
​Language: Python
​Libraries: pandas, numpy, matplotlib, seaborn
​
Summary of Findings & Key Insights
​Data Cleaning: Handled missing values, converted date columns to proper datetime formats, and standardized numerical metrics.
​Sales Distribution: Identified top-performing product categories driving the majority of revenue.
​Correlation: Analyzed relationships between unit prices, order quantities, and overall sales value.
​Outliers: Flagged extreme sales spikes during specific promotional windows.
​
How to Run the Notebook
​Ensure Python 3.x and required packages are installed (pandas, seaborn, matplotlib).
​Open Jupyter Notebook or VS Code.
​Run Task_2_EDA.ipynb sequentially to reproduce the analysis and charts.
